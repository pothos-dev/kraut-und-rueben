# Glossary

Domain vocabulary for kraut-und-rueben. Terms are added as they are
defined during planning.

## Terms

- **Shopping List** — the core domain object of the app: a named,
  ordered collection of items a user intends to buy. (Detailed shape
  still to be decided.)
- **List Item** — a single entry on a Shopping List. (Structure —
  free text vs. quantity/unit/category — still to be decided.)
